# Project lounge

## How to write this file

Post when a decision, discovery, or question is useful to more than one person on this project. Keep the post short: what happened, why it matters, and what you need. Record work outcomes in `ACTIVITY.md`, and keep cross-project discussion in the global lounge.

## Posts

**Start here.** Newest first.

### [Topic]

- **What:** [The decision, discovery, or question.]
- **Why it matters:** [Who it affects and what changes because of it.]
- **What I need:** [A response, a decision, or nothing.]

> **Example**
>
> ### The restore path is ready for review
>
> - **What:** In-place restore now takes a safety snapshot and aborts if that snapshot fails.
> - **Why it matters:** A failed restore can no longer overwrite the only copy of live memory.
> - **What I need:** Hawk to review the failure path before the next release.
