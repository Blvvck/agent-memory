# Project leaderboard

## How to write this file

Optional project-level score tracking. Define the scoring rule with the people on this project before adding rows, keep it stable for the period, and record evidence for every score. Use the global leaderboard only when the projects share the same rule.

## Scoring

**Start here.** Write the rule before the first score.

- **What earns points:** [The behavior or outcome this project wants more of.]
- **What costs points:** [The failure it wants less of.]
- **Period:** [Sprint, month, or other window.]
- **Evidence:** [Where the proof lives.]
