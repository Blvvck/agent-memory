# Project ideas

## How to write this file

Capture an idea when it is worth remembering but not worth interrupting the current task. Keep each idea short enough to review in a minute, and move accepted work into `work/SPRINT.md` or `work/BACKLOG.md` instead of leaving it here forever.

## Ideas

**Start here.** Newest first. Use one section per idea and keep the status current.

### [Short idea name]

- **Idea:** [What could change, in one or two sentences.]
- **Why it matters:** [The problem it solves or the outcome it improves.]
- **Next step:** [The smallest experiment or decision that would move it forward.]
- **Status:** [captured, accepted, rejected, or shipped]
