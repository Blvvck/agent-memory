# Project skills

Add skill files here when the knowledge applies to this project only. Shared skills belong in `~/.agent-memory/skills/`.

## How to write a skill

**Start here.** Create a skill when the knowledge is reusable and specific enough that another agent can follow it without asking what you meant. Use `<name>.md` for a single procedure or `<name>/SKILL.md` for a bundle, and put a one-line name and description in the frontmatter. For example, `release-checklist.md` can hold the steps this project runs before a deploy. Run `agent-memory skills` to rebuild the index below; do not edit the generated index by hand.
