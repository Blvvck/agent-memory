# Global tasks

## How to write this file

A task is a follow-up someone will do, not an idea and not a request for another person. Name the owner, the next action, the due date, and the condition that closes it. Move project work into that project's backlog, and use `NOTIFICATIONS.md` when someone else must act.

## Tasks

**Start here.** Add a row when the task becomes real, and update the status rather than deleting the row until it closes.

| Task | Owner | Next action | Due | Status |
|------|-------|-------------|-----|--------|
| [Task] | [Owner] | [Smallest next step] | [Date or none] | [open, blocked, or done] |
