# Human — History

Dated facts learned about the person, newest first, with how each was learned. This is a record, so entries are written with `agent-log` and carry a trace.

## How to write this file

Write an entry when you learn something durable about the person that does not fit `profile.md`, `preferences.md`, or `context.md`, or when you change one of those files in a way that matters. State how you learned it, and mark anything you inferred rather than were told.

Use the entry format and protected writer configured in the root `AGENTS.md`.

## Work Log

Newest first. Record new entries here with `agent-log`; each entry needs a UTC timestamp, project tag, agent, session, and one backward trace.

```text
[YYYY-MM-DDTHH:MM:SSZ] [project] @Agent [session:cli:ID]: What was learned, how, and whether it was told or inferred
- ↪ trace: relates-to [YYYY-MM-DDTHH:MM:SSZ] [project] @Agent [session:cli:ID]: The older entry
```

Entries start here.
