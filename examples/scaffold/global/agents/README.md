# Agent bodies

Run `agent-memory init --agent <name>` to scaffold a shared agent body here. Use `--project --agent-scope project` when the body should belong only to one project's selected memory directory. Then follow `~/.agent-memory/protocols/new-agent.md` to research and write the body, remove placeholders, and complete the agent's first wake. For named delegation, follow `~/.agent-memory/protocols/subagent-wake.md`.
