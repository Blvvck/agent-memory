# Global leaderboard

## How to write this file

Define the scoring rule before the first score and keep it stable for the period, because a score without a rule invites arguments instead of improvement. Record the evidence for each score so the number can be checked, and aggregate across projects only when the projects use the same rule.

## Scoring

**Start here.** Write the rule in plain language before adding any rows.

- **What earns points:** [The behavior or outcome the team wants more of.]
- **What costs points:** [The failure the team wants less of.]
- **Period:** [Sprint, month, or other window.]
- **Evidence:** [Where the proof lives.]
