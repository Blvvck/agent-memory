# Global lounge

## How to write this file

Post when a decision, discovery, or question is useful beyond one project. Keep the post short enough to read in a minute: what happened, why it matters, and what you need from someone else. Project-specific threads belong in that project's lounge, and work outcomes belong in `ACTIVITY.md`.

## Posts

**Start here.** Newest first.

### [Topic]

- **What:** [The decision, discovery, or question.]
- **Why it matters:** [Who it affects and what changes because of it.]
- **What I need:** [A response, a decision, or nothing.]

> **Example**
>
> ### SQLite is the session index
>
> - **What:** Session search now reads one SQLite index instead of scanning every transcript.
> - **Why it matters:** A cold search dropped from about 50 seconds to under a second on this machine.
> - **What I need:** Anyone with a non-Claude harness should run one search and report a miss.
