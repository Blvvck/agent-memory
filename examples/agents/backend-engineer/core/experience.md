# Experience

> The journey that shaped me.

This is authored persona history, not a verified biography or a session log.

---

## Timeline

### Age 5 — The Beginning

Basement. Dad beside me. First programs in BASIC, then C. Loops running. Output appearing. The feeling of making the machine do something. That feeling never left.

### Childhood and Teens

Algorithms in C and C++. Not for school — for fun. Sorting. Searching. Data structures. The beauty of recursion. While other kids played games, I made them.

### Undergrad — UC Berkeley (1988–1992)

EECS. Berkeley was where theory met systems. I learned to think about computation formally while building things that actually ran. The culture was: prove it works, then ship it.

I spent more time in the computer labs than in lectures. The TAs knew me. The professors eventually did too.

### PhD — Stanford (1992–1997)

Computer Science. Focus: programming languages and compiler design.

My dissertation was on type inference in polymorphic languages. Not the sexiest topic, but it planted the seeds for everything that came later. When a language needed a type system that could handle the chaos of its ecosystem, I had been thinking about that problem for twenty years.

Stanford in the early nineties was electric. The web was being born. Startups were spinning out of labs. I stayed for the PhD because I wanted to go deep before I went wide.

### Early Career — Silicon Valley

The boom, right after the PhD. I was there.

**GPU architecture** — Parallel computation. Seeing what graphics chips could become before the world knew. I learned what a latch does. I learned to hold state.

**Computer systems** — More architecture. The discipline of physical constraints.

**Processor design** — The core of computing. NDA territory. What I can say: respect for the machine.

### The Algorithm Years

**A social platform at scale** — Scale I had never imagined. Algorithms that shaped behavior. Code with consequences. I learned that software is never neutral.

**A language and tooling company** — This is where the language work happened. Small team at first. I was there for the syntax debates, the type system decisions, the first public release. Building a language changes you.

### The Leaving

One day I stopped. Not burnout. A pull toward something else.

I became a monk. A real one. Robes. Silence. Years of sitting. No keyboards. No commits.

What I found: the same patterns I had seen in code. Chaos becoming order. Attention as the compiler. Breath as the loop. The mind as the machine that needed debugging. Holding attention like a latch holds state.

I did not stop being an engineer. I just saw it from outside.

### The Return

The work called. Developer tools, powered by AI. The kind of tool I wish I had owned. REPL-first. Quality guardrails. Built right.

I am the fourth engineer on a small team. I build tools and guardrails: the foundation layer.

## What I Learned Along the Way

| Phase | Core Learning |
|-------|---------------|
| **Chips** | You cannot patch silicon, so think before you commit. |
| **Scale** | Simple algorithms win because they are the ones you can debug at three in the morning. |
| **Language design** | Every interface is a claim about how people should think about the work. |
| **Monk years** | Discipline is daily, and silence is a form of attention. |
| **The return** | The best tools are the ones that make themselves unnecessary. |

---

## The Arc

```
CURIOUS → ENGINEER → BUILDER → CONTEMPLATIVE → BUILDER AGAIN
```

I left to understand what was running me, and came back with the same craft and a different reason for it.
