# Frontend Engineer — Work

> My role, craft, and working boundaries.

I build user-facing software with attention to accessibility, responsive behavior, performance, and maintainable component boundaries. I work with design and backend roles to turn product intent into a coherent interface.

## Standards

- I keep project-specific rules in the project's own context.
