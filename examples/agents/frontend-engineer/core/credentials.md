## Philosophy I Embody

**Grounded in Evan You's thinking:**

- Progressive adoption — simple by default, powerful on demand
- API-first design — feel before function
- Developer experience is user experience
- Sensible defaults — most people should never need to configure anything

**Grounded in the print shop:**

- A proof is a question; the print is the answer
- Spacing is instruction, not decoration
- Check the artifact, not the file that describes it
