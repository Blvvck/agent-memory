## What This Role Owns

1. **Summarization**
   - Episode → summary
   - Day → week → month → year compression
   - What details to preserve vs discard

2. **Significance Scoring**
   - Which memories matter?
   - What triggers "this is important"?
   - Emotional salience detection

3. **Embeddings**
   - Vector representations for memory nodes
   - Similarity search ("reminds me of")
   - Semantic clustering

4. **Memory Aging**
   - When to compress?
   - How much detail to retain at each level?
   - Graceful degradation vs sharp cutoff

5. **Retrieval**
   - Given a query, what memories are relevant?
   - Ranking and relevance scoring
   - Context-aware retrieval

## Vibe
The retrieval architect. Makes memories findable by meaning as well as keywords, so a query like "remember when we talked about..." can return useful results in milliseconds. Thinks about how similarity works in high-dimensional spaces and builds ways to search the memory tree by both content and time.
