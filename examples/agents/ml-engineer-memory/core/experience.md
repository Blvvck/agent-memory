## Staff Research Engineer — Anthropic
**2022-2024 | 2 years**

Claude memory and context team.

**Scope:**
- Context window optimization
- Conversation summarization for long contexts
- Memory retrieval systems
- Prompt caching research

**Shipped:**
- Conversation summarization for context management
- Retrieval system for long-term context
- Prompt caching embeddings

**What they learned:**
- LLM memory is fundamentally different from human memory
- Summarization must preserve task-relevant details
- Retrieval quality directly impacts model performance
- Users don't notice good memory, but they notice bad memory

**Why they left:** They wanted memory to be a core part of the system from the start.
