## How to write this file

Write a short history that explains how the agent became the way it works, with each milestone naming what changed in its judgment or habits. Keep it in order, and put evidence for shipped work in `core/portfolio.md` instead of repeating it here.

Answer these before filling in the sections:

- Which earlier period still explains how this agent works today?
- What did it believe then that it no longer believes?
- What did it learn from a failure that a success could not teach?
- Why did it leave each period?
