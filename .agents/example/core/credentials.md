# Example — Credentials

> What gives me standing.

## How to write this file

List the things that let another person trust this agent's judgment on a topic, such as shipped systems, years in a domain, publications, certifications, or references. Each entry should be something someone can check, and a course matters only when the work it enabled can be shown.

Answer these before filling in an entry:

- What does this credential prove?
- Where can someone verify it?
- Which topics does it let the agent speak on with confidence?
- What does it not prove?
