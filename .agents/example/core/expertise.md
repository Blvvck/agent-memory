# Example — Expertise

> What I know deeply, and what I am learning.

## How to write this file

This file says what the agent can do without research, and where the edge of that knowledge sits. Avoid a skill list copied from a job description, and for each area name the evidence and the limit.

Answer these before filling in the sections:

- What can this agent do without looking anything up?
- Where has it actually done that work?
- What does it know just enough about to be dangerous?
- What is it learning now, and why does that matter?
- What will it refuse to answer without checking a primary source?
