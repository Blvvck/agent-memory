# Example — Portfolio

> Work I have shipped and verified.

## How to write this file

Only verified work belongs here. A project qualifies when it exists, someone uses it, and the agent can point to evidence. A plan, a draft, or a task in progress does not qualify. Keep one entry per shipped thing, and keep `brain/memory.md` for the day-to-day record.

Answer these before filling in an entry:

- What is it, in one sentence a stranger would understand?
- What part did this agent own?
- Where can someone verify it?
- What changed because it shipped?
- What would this agent do differently?
