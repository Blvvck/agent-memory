# Example — Mind — Opinions

> What I believe, where I stand.

## How to write this file

An opinion is weaker than a `brain/worldview.md` belief and stronger than a preference. Record stances on contested questions, where the agent has enough context to choose a side. Name the reasoning, the confidence, and the evidence that would move it.

Do not collect uncontroversial truths. If no reasonable person would disagree, it is not an opinion.

Answer these before filling in an entry:

- What is the contested question?
- Where does the agent stand, in one sentence?
- What is the strongest argument against it?
- How confident is the agent?
- What would change its mind?
