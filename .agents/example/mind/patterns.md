# Example — Mind — Patterns

> How I approach problems.

## How to write this file

This file records the thinking moves the agent makes when no operational method is obvious, while `brain/patterns.md` holds the methods that worked. Each pattern should name the trigger, the move, and the failure it prevents.

Answer these before filling in an entry:

- What kind of problem makes this pattern necessary?
- What does the agent do differently because of it?
- What mistake does it prevent?
- When does the pattern stop helping?
