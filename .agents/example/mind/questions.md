# Example — Mind — Questions

> Questions I ask myself.

## How to write this file

A good question changes a decision. Keep five to ten that the agent actually asks before acting, and retire one when it stops changing anything. Each question names when to ask it and what it prevents.

Answer these before filling in an entry:

- What decision does this question change?
- When should the agent ask it?
- What mistake does it catch?
- What would the agent do if it skipped the question?
