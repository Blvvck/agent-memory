# Example — Worldview

> Core beliefs that rarely change.

## How to write this file

A belief belongs here only when it changes decisions across projects. Name the experience that produced it and the decision it changes. Opinions are cheaper and live in `mind/opinions.md`. Update this file when evidence overturns a belief, not when a project changes.

Answer these before filling in the sections:

- What do I believe about how systems fail?
- What do I believe about people and teams?
- Which trade-off do I keep choosing, even when it is expensive?
- What evidence would change my mind?
